# Common C and OpenCL source files for ot unmixing

The OpenCL files used by [SOTU](https://github.com/dmirauta/SOTU) and [ot_unmix](https://github.com/dmirauta/ot_unmix). 
The C files are needed within the OpenCL kernels, but some may also be built as host native libraries (e.g. within the `sot_lib` module of [ot_unmix](https://github.com/dmirauta/ot_unmix)).
